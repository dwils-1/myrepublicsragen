Keluhan & Solusi

Temukan solusi untuk kendala yang sering terjadi saat melakukan pengaturan WiFi ZTE F670L.

01

Tidak Bisa Membuka 192.168.1.1

KENDALA

Halaman login router tidak muncul ketika alamat 192.168.1.1 dibuka.

Solusi
  1. Pastikan HP atau laptop terhubung ke WiFi router.
  2. Buka browser seperti Chrome, Safari, atau Firefox.
  3. Ketik 192.168.1.1 langsung pada address bar browser.
  4. Jangan mengetik alamat tersebut pada kolom pencarian Google.
02

Nama WiFi Baru Tidak Muncul

KENDALA

Setelah mengganti nama WiFi, jaringan dengan nama baru tidak terlihat pada HP atau laptop.

Solusi
  1. Pastikan SSID yang digunakan berada pada posisi On.
  2. Pastikan SSID Hide berada pada posisi Off.
  3. Klik tombol Apply.
  4. Matikan lalu nyalakan kembali WiFi pada perangkat.
03

Password WiFi Tidak Bisa Digunakan

KENDALA

Perangkat tidak dapat tersambung menggunakan password WiFi yang baru.

Solusi
  1. Periksa kembali password yang dimasukkan.
  2. Perhatikan huruf besar, huruf kecil, angka, dan simbol.
  3. Pilih jaringan WiFi kemudian gunakan opsi Lupakan jaringan.
  4. Sambungkan kembali menggunakan password baru.
04

WiFi Terputus Setelah Klik Apply

KENDALA

HP atau laptop terputus setelah konfigurasi disimpan.

Solusi
  1. Ini normal jika nama WiFi atau password telah berubah.
  2. Cari nama WiFi baru pada daftar jaringan.
  3. Masukkan password WiFi yang baru.
  4. Jika belum terlihat, refresh daftar WiFi atau tunggu beberapa saat.
05

WiFi 5GHz Tidak Muncul

KENDALA

Jaringan WiFi 5GHz tidak terlihat pada perangkat.

Solusi
  1. Pastikan SSID5 (5GHz) dalam posisi On.
  2. Pastikan SSID Hide dalam posisi Off.
  3. Klik Apply.
  4. Perangkat harus mendukung jaringan 5GHz agar dapat melihat jaringan tersebut.
06

Terhubung WiFi Tetapi Tidak Ada Internet

KENDALA

Perangkat berhasil tersambung ke WiFi tetapi internet tidak dapat digunakan.

Solusi
  1. Coba matikan dan nyalakan kembali WiFi pada perangkat.
  2. Coba sambungkan perangkat lain untuk memastikan masalah bukan hanya pada satu perangkat.
  3. Periksa indikator koneksi pada router.
  4. Jika semua perangkat tidak memiliki internet, hubungi support MyRepublic.
07

Perangkat Lama Tidak Bisa Terhubung

KENDALA

Perangkat yang sebelumnya terhubung tidak bisa tersambung setelah password WiFi diganti.

Solusi
  1. Pilih jaringan WiFi lama pada perangkat.
  2. Pilih Lupakan jaringan.
  3. Cari kembali nama WiFi yang baru.
  4. Masukkan password baru.
💡
Tips

Setelah mengganti nama atau password WiFi, perangkat yang sebelumnya tersambung kemungkinan perlu dihubungkan kembali menggunakan informasi WiFi yang baru.
